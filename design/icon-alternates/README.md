# Golazo icon alternates

Explorations only. The shipping assets in `electron/assets/` are intentionally unchanged.

All three concepts keep the current charcoal, acid-lime, and warm-cream palette and are drawn as editable SVGs at a 1024 px artboard.

## 01 — Goal siren

`01-goal-siren.svg`

The existing G becomes a loudspeaker/goal horn. The three broadcast marks make the exaggerated “GOOOOL” celebration readable without lettering. This is the closest relative of the current icon.

## 02 — Too much goal

`02-too-much-goal.svg`

An absurdly oversized ball has smashed through a tiny goal. It leans furthest into the joke behind “Golazo,” while the lime flight path quietly preserves a G-shaped gesture.

## 03 — VAR says done

`03-var-says-done.svg`

A goal-line monitor with a deliberately oversized approval check. It connects the football joke to Golazo’s actual job: deciding whether work is done.

## Evaluation order

1. Test at 32 px and 16 px before refining details.
2. Pick the attitude first: loud, absurd, or dry.
3. Only then build the platform icon sizes and `.icns`; the production icon generator remains the source of truth until a direction is selected.
